# RMT development

RMT is an independent discovery and application launcher. Preserve the graphite/lime brand, mobile usability, free standard listings, and optional clearly labeled promotional placements. The current release links to external project experiences.

Keep publication state and reviewer authorization on the server. Pending applications and private contact/evidence must not appear in the public catalog. Keep admin identity configuration in runtime secrets. Source project claims and real destination links; do not invent partnerships, players, download counts, or revenue.

Run `npm run typecheck`, `npm test`, and `npm run build` for substantial application changes. Database migrations already applied are immutable. Keep dependency lockfiles, original project attribution, and the existing source history. Read `docs/deployment.md` before changing hosting or authentication.
